How it works

  2. Your browser encrypts it before upload.
  3. Share the link. It expires automatically.

Questions

Can the server read my file?

The decryption key stays in the link fragment, which browsers do not send in requests. The Worker stores ciphertext only.

Can I delete the link early?

Yes. Keep the delete token returned when the link is created in this page.
