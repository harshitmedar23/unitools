CSV to JSON

The first row is used as column names. Quoted commas are supported.

Download data.json

How it works

  1. Paste CSV or choose a local file.
  2. Press Convert to JSON.
  3. Download the JSON array.

Questions

Can cells contain commas?

Yes. Standard double-quoted CSV cells with escaped quotes are supported.
