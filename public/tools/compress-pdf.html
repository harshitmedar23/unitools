How it works

  1. Add one PDF.
  2. Choose light or strong compression.
  3. Download the smaller file.

Questions

What is strong compression?

Each page is rendered as a JPEG image and rebuilt into a PDF. Text can no longer be selected.

Will every PDF become smaller?

No. If the result is not smaller, the original file is returned.
