How it works

  1. Choose a PDF with selectable text.
  2. Text is extracted page by page.
  3. Download the Markdown file.

Questions

Does this OCR scanned pages?

No. It extracts text already stored in the PDF. Scanned-page OCR is not available yet.

Will the original layout be preserved?

No. The output uses page headings and extracted text; columns, images and precise formatting are not retained.
