How it works

  2. Choose indentation and optional key sorting.
  3. Format or minify, then copy the result.

Questions

Where is the error?

Invalid JSON is reported with its line and column when the browser provides that detail.

Can it preserve big integers?

JSON parsed by this browser tool may lose precision for integers outside JavaScript's safe range.
